1. **==IaaS== (Infrastructure as a Service)**  
   - Memberikan akses ke sumber daya komputasi dasar seperti server, penyimpanan, dan jaringan secara virtual.  
   - Pengguna bertanggung jawab atas sistem operasi, aplikasi, dan data mereka sendiri.  
   - Contoh: Microsoft Azure, Amazon Web Services (AWS), Google Cloud Platform (GCP).

1. **==PaaS== (Platform as a Service)**  
   - Menyediakan lingkungan pengembangan yang sudah dilengkapi dengan sistem operasi, [[runtime]], dan alat pengelolaan aplikasi.  
   - Pengguna hanya perlu fokus pada pengembangan dan penerapan aplikasi tanpa khawatir tentang infrastruktur.  
   - Contoh: Google App Engine, Microsoft Azure App Service, Heroku.

1. **==SaaS== (Software as a Service)**  
   - Aplikasi siap pakai yang bisa langsung digunakan tanpa perlu instalasi atau pemeliharaan oleh pengguna.  
   - Segala aspek terkait pemeliharaan, keamanan, dan infrastruktur dikelola oleh penyedia layanan.  
   - Contoh: Google Workspace, Microsoft 365, Dropbox.

4. **FaaS (Function as a Service)**  
   - Model ==komputasi== serverless yang memungkinkan ==eksekusi kode dalam bentuk fungsi kecil== tanpa harus mengelola server.  
   - Sangat efisien untuk aplikasi berbasis ==event-driven== seperti pemrosesan data secara real-time.  
   - Contoh: AWS Lambda, Azure Functions, Google Cloud Functions.

5. **XaaS (Everything as a Service)**  
   - Konsep luas yang mencakup berbagai layanan berbasis cloud, termasuk IaaS, PaaS, SaaS, dan lainnya seperti DaaS (Desktop as a Service), BaaS (Backup as a Service), dan lainnya.  
   - Membantu perusahaan mengakses berbagai solusi teknologi tanpa harus memiliki atau mengelola infrastruktur sendiri.

CASB (==Cloud Access Security Broker==) : solusi keamanan yang berfungsi sebagai perantara antara pengguna dan layanan cloud untuk memastikan perlindungan data serta kepatuhan terhadap kebijakan keamanan.
- membantu organisasi mengontrol dan mengamankan akses ke aplikasi cloud

A cloud access security broker (CASB) is a security tool that sits between users and cloud applications to ==monitor activity and enforce security policies==.

CASB vendors offer their services as cloud-hosted software, although some CASBs also offer on-premise software or on-premise hardware appliances.

## Empat Pilar 

1. **Visibility** :  discover "shadow IT": systems and processes, especially cloud services, that are not officially documented and that may introduce unknown security risks.
2. **Data security** : prevent confidential data from leaving company-controlled systems, and help protect the integrity of that data.
	- access control ,
	- data loss prevention (DLP)
3. **Threat protection** : block external threats and attacks,
	-  Anti-malware detection, sandboxing,
	- packet inspection,
	- URL filtering and
	- browser isolation
4. **Compliance** :  implementing strong security control to achieve regulatory compliance.
	- SOC 2, HIPAA, or the GDPR.

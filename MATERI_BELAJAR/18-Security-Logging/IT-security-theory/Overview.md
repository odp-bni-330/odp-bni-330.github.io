
###  Security Cloud Computing

**Konsep Dasar:**  
- Keamanan dalam [[Model Layanan Cloud]]
- Shared Responsibility Model (tanggung jawab keamanan antara provider dan user).  

**Sub-Topik Penting:**  
- **Ancaman Cloud:**  
  - Data breaches, misconfiguration, insecure APIs, account hijacking.  
- **Best Practices:**  
  - Enkripsi data (at rest & in transit), multi-factor authentication (MFA), identity and access management (IAM).  
- **Tools/Platform:**  
  - AWS Security Hub, Azure Security Center, Google Cloud Security Command Center.  
- **Regulasi:**  
  - Compliance standar seperti GDPR, ISO 27001, atau CSP-specific (e.g., AWS Well-Architected Framework).  

**Persiapan:**  
- Pelajari istilah: CASB (Cloud Access Security Broker), Zero Trust Architecture.  
- Baca dokumentasi keamanan dari provider cloud (AWS/Azure/GCP).

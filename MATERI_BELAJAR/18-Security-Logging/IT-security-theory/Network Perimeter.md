[Firewalls](https://www.cloudflare.com/learning/security/what-is-a-firewall/) were designed to defend the network perimeter by blocking malicious external network traffic.

With the [cloud](https://www.cloudflare.com/learning/cloud/what-is-the-cloud/), the network perimeter essentially no longer exists. Employees access cloud data and applications over the unsecured Internet instead of the IT-managed internal network. Users access internal data from any device or physical location.

The use of [remote desktop software](https://www.cloudflare.com/learning/access-management/remote-workforce-security/) also erodes the network perimeter

Even without a traditional network perimeter, it is possible to tightly restrict access to data in order to [keep it secure](https://www.cloudflare.com/learning/access-management/what-is-remote-access-security/). [Cloudflare Zero Trust](https://www.cloudflare.com/zero-trust/) helps organizations manage user access without relying on a [VPN](https://www.cloudflare.com/learning/access-management/what-is-a-vpn/) — instead, internal data and resources are protected by the [global Cloudflare network](https://www.cloudflare.com/network/). Cloudflare [Magic WAN](https://www.cloudflare.com/magic-wan/) enables enterprises to configure a [wide area network (WAN)](https://www.cloudflare.com/learning/network-layer/what-is-a-wan/) that automatically includes security features.

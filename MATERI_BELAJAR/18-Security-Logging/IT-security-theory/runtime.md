**Runtime** adalah periode ketika sebuah program atau aplikasi sedang dieksekusi oleh komputer setelah dikompilasi atau diinterpretasikan. Ini mencakup semua proses yang terjadi saat kode berjalan, seperti alokasi memori, eksekusi instruksi, dan interaksi dengan sistem operasi atau perangkat keras.

Secara umum, runtime dapat dikaitkan dengan beberapa konsep penting:
- **Runtime Environment**: Lingkungan tempat aplikasi dijalankan, termasuk pustaka, dependensi, dan interpreter atau virtual machine jika diperlukan (contoh: Java Runtime Environment).
- **Runtime Error**: Kesalahan yang muncul saat program sedang dieksekusi, seperti pembagian oleh nol atau akses ke memori yang tidak valid.
- **Runtime Libraries**: Kumpulan fungsi yang digunakan oleh program saat berjalan, seperti pustaka standar dalam C atau runtime .NET.

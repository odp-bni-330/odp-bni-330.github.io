# ETL dengan Python

## Cara menjalanakan

0. pada terminal, pindah ke direktori `./newbanks`

1. buat virtual environment python

```bash
python -m venv venv
source venv/bin/activate       # Linux/Mac
venv\Scripts\activate          # Windows
```

2. unduh library yang dibutuhkan

```bash
# install kernel python untuk jupyter notebook
pip install ipython ipykernel

# install library yang dibutuhkan
pip install pandas seaborn matplotlib numpy
```

## Catatan

Pastikan pada VSCode sudah mengintsall extension jupyter notebook.
